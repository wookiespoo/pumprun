Pricedown (Ray Larabie / Typodermic) — freeware GTA-style display font.

Drop pricedown.otf / .ttf / .woff here as:
  assets/fonts/pricedown.woff2
  assets/fonts/pricedown.woff
  assets/fonts/pricedown.otf
  assets/fonts/pricedown.ttf

The CSS also loads Pricedown from fonts.cdnfonts.com so the UI still
gets the GTA face if the local file is missing.
